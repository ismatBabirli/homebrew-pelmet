# Homebrew Pelmet

Homebrew tap for [Pelmet](https://pelmet.xyz), a macOS menu bar organizer that
reclaims the icons a MacBook notch hides.

```bash
brew install --cask ismatBabirli/pelmet/pelmet
```

Website: [pelmet.xyz](https://pelmet.xyz) &nbsp;·&nbsp; Source:
[ismatBabirli/pelmet](https://github.com/ismatBabirli/pelmet)

The cask here is a copy. The canonical version lives at
`packaging/homebrew/pelmet.rb` in the app repository, and the release workflow
keeps this copy's `version` and `sha256` in sync on every tagged release.
